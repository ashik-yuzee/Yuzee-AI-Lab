Three ways to run Oala, compared

Vanilla (AI Studio) · EXP-RAG · Multi-Agent  ·  Yuzee AI Token Lab  ·  test run 5 October 2026

We asked all three modes the same 11 questions. Two independent AI judges ranked the answers without knowing which mode wrote which. On quality the three modes were effectively tied. Their average places were 1.82 for Vanilla, 1.91 for Multi-Agent and 1.95 for EXP-RAG (out of 3), a gap too small to call on 11 questions. EXP-RAG was the fastest, with a typical answer finished in 14.8 s (16.6 s for Multi-Agent and 17.6 s for Vanilla). EXP-RAG was the cheapest at $0.0027 per answer, about a quarter of a US cent, 31% less than Vanilla; Multi-Agent cost $0.0033 and Vanilla cost $0.0039. Overall, EXP-RAG led on speed and cost.

How each mode works

Vanilla (AI Studio)

Oala gets the full instruction book on every question: about 46,000 tokens (a token is roughly three-quarters of a word). It also gets facts looked up from our data warehouse. One model call writes the answer, then a review step checks it. Simple and complete, but the model reads a lot of text it does not need.

EXP-RAG

Oala keeps a short core set of rules that is stored and reused, so it is cheap to resend. For each question it adds only the guidance, warehouse facts and memory of the chat that this question needs. The model reads far less text for the same job.

Multi-Agent

EXP-RAG plus a team of small, fast helper models. Each helper has one narrow job (profile, jobs, skills, market, courses, pathway, company or opportunities) and searches the warehouse for itself. They work at the same time. Their findings are merged and checked against the evidence, and Oala writes one answer from them. Simple questions skip the team.

Why isn't Multi-Agent much faster?

The helpers do work side by side, as the timeline above shows. But the final answer is still written by one model after they finish, and that writer's careful thinking (a few seconds) is what makes the answers good. Working in parallel can shorten the gathering, not the writing. We cut the team's part from 5–8 s to about 2 s after the data lookup. Turning the writer's thinking down made Multi-Agent the fastest mode on team questions (13.7 s typical), but blind judges ranked those answers last. So the default keeps careful thinking, and "Low" in the thinking menu is the fast option.

What we changed to make it faster

  • Helpers now answer in a smaller, fixed format, so each one takes about 2 s.
  • The Pathway helper works alongside the others instead of waiting for all of them.
  • The Market check no longer waits about 2 s for graph and forecast data. Oala still receives that data.
  • Answers name their sources, do not push a generic follow-up question, and name local providers when a place is given.
  • One kind of broken answer format is now repaired automatically, for every mode.

Method and limits

  • 11 questions from 10 conversations, including follow-up questions. Each mode answered each question once.
  • All modes used the same main model (gemini-3.7-flash), the same warehouse data and the same answer checks. Only the way the prompt is built differs.
  • The tests ran on a separate copy of the server, so no real users or shared data were involved.
  • Answers were judged blind by two AI judges. AI judges can be wrong, and they do not always agree.
  • This is a small sample. A different set of questions could change the order, especially where the gaps are small.
  • Gemini's speed changes from run to run and hour to hour, so treat time differences under a couple of seconds as noise.
  • Vanilla and EXP-RAG answers, and the Multi-Agent answers to simple questions, come from one test session (round 3). Multi-Agent team answers and the fast setting come from a session about an hour later (round 4), so speed carries some session-to-session noise.
  • Round 3's Multi-Agent team answers used an earlier low-thinking setup and are not in the headline.
  • Total Gemini spend for all evaluation rounds, including warm-ups and smoke tests, was about $0.42.
