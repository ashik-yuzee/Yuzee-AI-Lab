Multi-Agent mode

What was added to GitHub, how the new mode works, and the pixel-art team window · 5 October 2026

In one paragraph. Multi-Agent is a third way to run Oala, next to Vanilla (AI Studio) and EXP-RAG. When a question needs it, a small team of specialist AI helpers works on it at the same time. Each one has one narrow job and looks up its own evidence in the Yuzee data warehouse. Their findings are checked and merged, and Oala then writes one answer with clear next steps. Simple questions skip the team. The user can watch the team work in the chat and in an optional pixel-art office window.
8 specialistsProfile, Jobs, Skills, Market, Company, Learning, Pathway, Opportunity
Works in parallelSpecialists run side by side, about 2 s after the data lookup
Evidence-checkedAnything a specialist cannot back with a record is removed

2. How the Multi-Agent mode works

Multi-Agent is built on EXP-RAG. Oala still uses EXP-RAG’s short cached core prompt, picks only the guidance and warehouse evidence this question needs, keeps a rolling memory of the chat, and checks the answer before it is shown. The new part is the team that works before Oala writes.

Step 1 — The complexity gate decides how much help is needed

LevelExampleWhat happens
0 · direct“What does RPL mean?”Oala answers straight away. No team, no extra cost.
1 · lookup“How many UX designer jobs are in Perth?”One specialist does the data lookup only (no AI call). A one-line status is shown.
2 · personal“Am I suitable for UX designer jobs?”Profile plus one or two domain specialists.
3 · planning“I want to move from hospitality into UX design.”Five or six specialists, including Pathway, run side by side.
4 · action“Find jobs I can realistically apply for and help me close the gaps.”The full team, plus opportunities beyond the request.

The gate uses fast rules, so it adds no delay. When the warehouse’s own planner (which runs anyway) understands the question better, it can add specialists, never remove them.

Step 2 — Specialists work at the same time

SpecialistIts one jobWaits for
ProfileReads what the user has told us about themselves and lists what is missing. The only helper that sees personal profile data.nothing
JobsJob records, common titles, recurring requirements, and related roles the user did not search for.data lookup
SkillsCompares the user with what employers ask for, and ranks the gaps.Profile
MarketDemand signals, each labelled historical, current, inferred or uncertain. Never invents a trend.data lookup
CompanyWhat a named employer asks for. Says plainly when there is no data about that employer.data lookup
LearningThe smallest course, skill set or unit that closes a gap, with local providers when a place is named.data lookup
OpportunityRelated roles, traineeships and placements that could fit better than the literal request.Profile
PathwayUp to three realistic routes, the best one, and the best next action.Profile

Each specialist is one fast AI call (Gemini 3.5 Flash-Lite) with a narrow task and a small, fixed answer format, so each takes about 2 seconds. Each one also runs its own search of the warehouse catalogue (the EXP-RAG index of qualifications, courses, units, occupations and providers), so it fetches the data it needs for its own job.

Step 3 — Evidence is checked and merged

  • Every finding must cite records the specialist was actually given. Findings that cite nothing real are removed, and that removal is shown as a warning.
  • Facts (from records) are kept apart from interpretations (the specialist’s judgement).
  • Duplicates are removed without inflating confidence. If two specialists disagree, both views are kept as nuance.
  • Old records are flagged, and missing information is listed.
  • A short answer plan is prepared: best route, best next step, main gaps, and options beyond the request.

Step 4 — Oala writes one answer

Oala receives the merged findings next to the usual EXP-RAG evidence and writes one answer, never a list of agent reports. The answer gives the direct answer first and says in one sentence what was checked. It ties advice to what the user said, names its sources, and gives the best next step. It asks at most one useful question. If a specialist did not finish, Oala says so plainly instead of guessing. A short review then checks the answer before it is shown.

Step 5 — Failures, cancelling and saving

  • Timeouts: each specialist has a limit (5–6.5 s). A slow or failed specialist never breaks the answer; it is marked “didn’t finish”.
  • Cancelling: pressing Stop, or sending a new question in the same chat, stops the specialists still running.
  • Saving: the team’s work (plan, findings, sources, timings, cost) is saved on the message. It reappears after a reload, and a profile review can be reused later in the same chat.
  • Cost tracking: every specialist call is billed with the turn and shown in the token telemetry.

What the user sees

  • Expandable results: each specialist card opens to show its facts, interpretations, sources and how recent they are, its confidence, and anything missing.
  • Next steps: buttons such as “Compare UX courses”, “Build this pathway” or “Add your missing details” send a follow-up, open the mini pathway, or open the profile editor.
  • Accessibility and phones: status changes are announced to screen readers, buttons work with the keyboard, animation is off for reduced motion, and the panel becomes a simple list on phones.

How it compares (blind test, 11 questions)

ModeQuality (average place, 1 = best)Typical timeFirst wordsCost per answer

On quality the three modes are effectively tied. Multi-Agent is faster than Vanilla and slower than EXP-RAG: the specialists work in parallel, but the final answer is still written by one model after they finish, and that careful writing is what keeps quality high. The full comparison is in docs/reports/multi-agent-comparison.pdf.

3. Additional: the pixel-art team window

An optional, playful view of the same real work. It shows the team as characters in a small pixel-art office, built with the open-source Pixel Agents project.

How to use it

  • Only in Multi-Agent mode: a team button appears beside the message box, with a badge counting the specialists working right now.
  • Open and close: click the button to open the window; press Esc or the × to close it.
  • Move it: drag the window by its header. When you let go it snaps to the nearest edge or corner and stays there, even after a reload. Keyboard users can move it with the arrow keys on the grip.
  • Minimise: the arrow button collapses the window to its header. On phones the window is a bottom sheet.

Nothing in the office is staged: every pose comes from the same live events as the chat panel. A text list under the office repeats the same information for screen readers. Animation stops when nothing is changing, when the window is closed, or when the tab is hidden.

4. Known limits and next steps

Gemini credits. The project’s Gemini prepaid credits ran out on 5 October 2026 (error 402). Until they are topped up in AI Studio, no mode can answer, and the EXP-RAG test that calls Gemini fails.
  • Speed versus quality: lowering Oala’s thinking makes Multi-Agent the fastest mode, but the answers rank lower, so the default keeps careful thinking. The first version (Pathway waiting for all specialists, more detailed notes) ranked best on quality but was about 5 s slower than EXP-RAG. It can be re-tested once credits are back.
  • Not merged yet: the work is on the feature branch, not main.
  • Journey: the spec’s later phases (persistent agents that keep working between chats, a saved personal journey) are not built. Team results are saved on each message.
  • Small test: quality was judged on 11 questions by two AI judges. A larger set would give firmer numbers.
